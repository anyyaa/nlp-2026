# Новые языки программирования

Учебный проект: 20 самостоятельных программ на 20 разных языках.

## Требования курса

| Тема | Количество |
|---|---:|
| Многопоточность | 4 |
| Алгоритмические задачи | 4 |
| Ввод/вывод в консоль/файл | 4 |
| Клиент-серверное взаимодействие | 4 |
| Конвертация данных | 4 |

Не менее двух алгоритмических работ должны использовать рекурсию. Следует избегать специализированных библиотек: алгоритмы реализуются самостоятельно, возможности стандартной библиотеки описываются в README работы.

## Список задач

Пункты 1.3, 1.4, 2.1, 3.4, 4.2, 5.1 и 5.2 заменены новыми заданиями с учётом замечания о совпадениях. Остальные 13 заданий сохранены. Рекурсивные задачи — 2.1 и 2.2.

## 1. Многопоточность

### 1.1 Параллельный подсчёт частот слов
Разбить текст по границам слов. Потоки считают частоты локально; результаты объединяются. Зафиксировать правила регистра и пунктуации. Проверить пустой текст и совпадение с последовательным подсчётом.

### 1.2 Параллельный поиск простых чисел
Разделить [l, r] между потоками без пропусков и пересечений. Объединить и отсортировать простые числа. Проверить диапазоны с отрицательными числами, 0, 1 и границы частей.

### 1.3 Параллельное вычисление гистограммы чисел

Считать из файла целые числа и границы диапазона. Разделить последовательность между потоками; каждый поток строит локальную гистограмму распределения по K равным интервалам. Объединить частоты и отдельно вывести количество значений вне диапазона. Последний интервал включает правую границу. Проверить совпадение с последовательным подсчётом, пустой вход и числа на границах интервалов.

### 1.4 Параллельный поиск ближайшей пары точек

Для набора двумерных точек найти пару с минимальным евклидовым расстоянием. Распределить пары индексов i < j между потоками; каждый сохраняет локальный минимум, затем результаты объединяются. При равных расстояниях выбирать лексикографически меньшую пару индексов. Использовать перебор без специализированных библиотек. Сравнить результаты и время при одном и нескольких потоках; проверить совпадающие точки и вход менее чем из двух точек.

## 2. Алгоритмические задачи

### 2.1 Рекурсивное вычисление арифметического выражения

Реализовать рекурсивный спуск для целочисленных выражений с операциями +, -, *, /, круглыми скобками и унарным минусом. Учесть приоритеты; деление целочисленное с усечением к нулю. Не использовать eval и готовые парсеры. Рекурсия обрабатывает вложенные скобки и унарный минус. Вывести результат либо позицию ошибки. Проверить 2*(3+4) → 14, -(-5) → 5, деление на ноль, незакрытые скобки и лишние символы.

### 2.2 Лабиринт
Рекурсивным DFS найти путь между началом и концом в двумерном лабиринте. Отмечать посещённые клетки; вывести путь либо отсутствие пути. Проверить циклы, недостижимый конец и совпадение начала и конца.

### 2.3 Возрастающая подпоследовательность
Определить длину наибольшей строго возрастающей подпоследовательности и восстановить один вариант. Проверить повторяющиеся числа, убывающую и пустую последовательности.

### 2.4 Интервалы
Объединить пересекающиеся закрытые интервалы [l, r]. Интервалы с общей граничной точкой объединяются. Проверить вложения, одинаковые интервалы и неверное l > r.

## 3. Ввод и вывод в консоль и файл

### 3.1 Экзамен
Считать имена и баллы из файла; вычислить средний, минимум, максимум и количество сдавших. Порог сдачи задаётся явно. Сохранить отчёт. Обработать пустой файл и неверные баллы.

### 3.2 Матрица
Считать размеры и матрицу из файла; вычислить суммы строк и столбцов и максимумы строк. Записать результаты в другой файл. Проверить количество элементов и неверные размеры.

### 3.3 Журнал
Разобрать строки timestamp level message, подсчитать уровни и сохранить ошибки за заданный период. Формат времени — YYYY-MM-DD HH:MM:SS; границы периода включены. Сообщить номера неверных строк.

### 3.4 Формирование отчёта о личных расходах

Считать из UTF-8 файла записи дата;категория;сумма. Через консоль задать период отчёта, вывести общую сумму и расходы по категориям, сохранить подробный отчёт в отдельный файл. Суммы хранить в целых копейках, даты — YYYY-MM-DD; границы периода включены. Сообщать номера неверных строк. Проверить пустой период, несколько категорий и неверные даты или суммы.

## 4. Клиент-серверное взаимодействие

### 4.1 Строковый сервер
Клиент отправляет строку и команду: смена регистра, разворот или длина. Сервер возвращает результат либо ошибку. Определить кодировку и единицу длины строки; проверить неизвестную команду.

### 4.2 Клиент-серверная игра «Быки и коровы»

Сервер создаёт для каждого клиента секрет из четырёх различных цифр, первая цифра ненулевая. Клиент отправляет догадки; сервер возвращает число быков (верная цифра на верной позиции) и коров (верная цифра на другой позиции), а также число попыток. Реализовать команды новой игры и выхода, независимые сеансы по TCP. Проверить повторы цифр, неверную длину, победу и одновременную игру двух клиентов. Для проверок разрешить серверу фиксированный секрет.

### 4.3 Ручной HTTP-клиент
Отправить GET по TCP и самостоятельно разобрать статус, заголовки и тело. Учебный объём: HTTP/1.1 без TLS, с Connection: close; поддержать Content-Length и тело до закрытия. Неподдерживаемую Transfer-Encoding явно отклонить. Проверять на локальном сервере с фиксированными ответами.

### 4.4 Чат
Сервер обслуживает несколько клиентов и пересылает сообщения. Команды: имя, список участников, выход. Зафиксировать UTF-8 протокол строк и обработку отключения клиента. Проверить одновременное подключение минимум двух клиентов.

## 5. Конвертация данных из одного формата в другой

### 5.1 Конвертация Intel HEX в бинарный файл

Самостоятельно разобрать текстовые записи Intel HEX и сохранить байты в бинарный файл. Учебный объём: записи данных типа 00 и конца файла типа 01, 16-битные адреса; остальные типы явно отклонять. Проверять длину записи и контрольную сумму, пересекающиеся адреса считать ошибкой. Выход начинается с адреса 0, пропуски до максимального записанного адреса заполнить нулями. Проверить запись :03000000010203F7 → байты 01 02 03 и завершение :00000001FF.

### 5.2 Конвертация текста в код Морзе и обратно

Преобразовать UTF-8 текст с латинскими буквами A–Z и цифрами 0–9 в текстовый код Морзе и выполнить обратное преобразование. Символы кода разделять одним пробелом, слова — разделителем /; регистр исходных букв не сохраняется. Таблицу соответствий задать в программе. Отклонять неподдерживаемые символы и неизвестные комбинации. Проверить SOS → ... --- ..., цифры, несколько слов и пустую строку.

### 5.3 CSV → XML
Первая строка CSV задаёт названия полей. Разобрать кавычки, разделители внутри кавычек и удвоенные кавычки; экранировать XML. Для произвольных заголовков использовать элементы field с атрибутом name, а не превращать заголовок в имя XML-тега. Проверить неверное число столбцов.

### 5.4 BMP → PGM
Разобрать несжатый 24-битный BMP; учитывать смещение пикселей, порядок BGR, выравнивание строк и направление высоты. Преобразовать RGB в серый по объявленной формуле и сохранить PGM P5. Отклонить неподдерживаемые варианты BMP. Проверить ширину с padding и усечённый файл.
