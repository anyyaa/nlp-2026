# 2.3. Наибольшая возрастающая подпоследовательность

**Язык:** Swift  
**Тема:** Алгоритмические задачи  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1q7rL3yoLUzLOeWOWFGTe7SdyhPeUNZej/view?usp=sharing)

## Описание задачи

Реализовать алгоритм поиска наибольшей строго возрастающей подпоследовательности (LIS).

Программа должна определить максимальную длину возрастающей подпоследовательности и восстановить один из возможных вариантов.

Для решения используется динамическое программирование. Учитываются повторяющиеся числа, убывающие и пустые последовательности.

## Запуск

**Онлайн-компилятор:** https://onecompiler.com/swift

1. Открыть OneCompiler и выбрать Swift.
2. Вставить содержимое `main.swift` в редактор.
3. Нажать **Run**.
4. Результаты появятся в области Output.

Ввод через STDIN не требуется — тестовые последовательности заданы в коде.

## Реализация

Основная функция — `longestIncreasingSubsequence`.

Используются следующие структуры:

- `dp` — длины наибольших возрастающих подпоследовательностей для каждого элемента.
- `previous` — индексы предыдущих элементов для восстановления результата.
- `bestEnd` — индекс последнего элемента самой длинной подпоследовательности.

Алгоритм перебирает элементы с помощью двух вложенных циклов, после чего восстанавливает найденную подпоследовательность.

**Временная сложность:** `O(n²)`.  
**Дополнительная память:** `O(n)`.

## Тестирование

В программе предусмотрено 5 тестовых сценариев:

| Тест | Ожидаемый результат |
|---|---|
| `[10, 9, 2, 5, 3, 7, 101, 18]` | Длина 4, `[2, 5, 7, 101]` |
| `[2, 2, 2, 2]` | Длина 1 |
| `[5, 4, 3, 2, 1]` | Длина 1 |
| `[]` | Длина 0 |
| `[1, 2, 3, 4, 5]` | Длина 5 |
