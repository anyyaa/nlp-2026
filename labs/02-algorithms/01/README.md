# 2.1. Рекурсивное вычисление арифметического выражения

**Язык:** OCaml  
**Тема:** Алгоритмические задачи  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1HLtgREYP50BiBUcSn1j6TlasnKs-IWWw/view?usp=sharing)

## Описание задачи

Реализовать вычисление целочисленных арифметических выражений методом рекурсивного спуска без использования `eval` и готовых парсеров.

Поддерживаются операции `+`, `-`, `*`, `/`, унарный минус и вложенные скобки. Программа учитывает приоритет операций, выполняет целочисленное деление с усечением к нулю и выводит позицию ошибки при некорректном вводе.

## Запуск

**Онлайн-компилятор:** https://onecompiler.com/ocaml

1. Открыть OneCompiler и выбрать OCaml.
2. Вставить содержимое `main.ml` в редактор.
3. Нажать **Run**.
4. Результаты появятся в области Output.

Ввод через STDIN не требуется — тестовые выражения заданы в коде.

## Реализация

Программа использует четыре основные функции:

- `parse_expression` — сложение и вычитание.
- `parse_term` — умножение и деление.
- `parse_unary` — унарный минус.
- `parse_primary` — числа и скобки.

Вложенные выражения обрабатываются рекурсивно. Ошибки передаются через исключение `Parse_error`.

## Тестирование

В программе предусмотрено 13 тестовых выражений, включая:

| Выражение | Результат |
|---|---|
| `2*(3+4)` | `14` |
| `-(-5)` | `5` |
| `7/-2` | `-3` |
| `3/0` | Ошибка деления на ноль |
| `2*(3+4` | Ошибка незакрытой скобки |
| `2+3abc` | Ошибка лишних символов |
