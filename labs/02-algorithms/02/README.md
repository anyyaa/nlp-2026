# 2.2. Поиск пути в лабиринте

**Язык:** Prolog  
**Тема:** Алгоритмические задачи  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1B9RiqHo-rA9cmUQ3IbbUIpyQY42Ey4Cz/view?usp=sharing)

## Описание задачи

Реализовать поиск пути между начальной и конечной точками двумерного лабиринта с помощью рекурсивного поиска в глубину (DFS).

Лабиринт представлен двумерным списком, где `0` — свободная клетка, `1` — стена.

Программа учитывает препятствия и посещённые клетки, предотвращает зацикливание и выводит найденный путь либо сообщение о его отсутствии.

## Запуск

**Онлайн-компилятор:** https://onecompiler.com/prolog

1. Открыть OneCompiler и выбрать Prolog.
2. Вставить содержимое `main.pl` в редактор.
3. Нажать **Run**.
4. Результаты появятся в области Output.

Ввод через STDIN не требуется — тестовые лабиринты заданы в коде.

## Реализация

Основные предикаты программы:

- `free_cell` — проверка доступности клетки.
- `move` — перемещение в четырёх направлениях.
- `seen` — проверка посещённых клеток.
- `dfs` — рекурсивный поиск пути в глубину.
- `solve` — запуск поиска и получение первого найденного пути.
- `reverse_list` — восстановление правильного порядка клеток.

При попадании в тупик Prolog использует механизм возврата (backtracking) для поиска альтернативного пути.

## Тестирование

В программе предусмотрено 4 тестовых сценария:

| Тест | Ожидаемый результат |
|---|---|
| Обычный лабиринт | Путь найден |
| Лабиринт с циклом | Путь найден без зацикливания |
| Недостижимая конечная точка | `Path not found` |
| Начало совпадает с концом | `Path: [(0,0)]` |
