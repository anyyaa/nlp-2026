# 2.4. Объединение пересекающихся интервалов

**Язык:** Haskell  
**Тема:** Алгоритмические задачи  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1R2TAFXpBAS41Zp4Rh-jDi79bONVYkHFb/view?usp=sharing)

## Описание задачи

Реализовать алгоритм объединения пересекающихся интервалов.

На вход подаётся список интервалов `[l, r]`, каждый из которых задаётся левой и правой границами.

Программа должна объединить все пересекающиеся и соприкасающиеся интервалы и вывести итоговый список без пересечений.

## Запуск

**Онлайн-компилятор:** https://onecompiler.com/haskell

1. Открыть OneCompiler и выбрать Haskell.
2. Вставить содержимое `main.hs` в редактор.
3. Нажать **Run**.
4. Результаты появятся в области Output.

Ввод через STDIN не требуется — тестовые интервалы заданы в коде.

## Реализация

Основная функция — `mergeIntervals`.

Алгоритм состоит из нескольких этапов:

- `sort` — сортировка интервалов по левой границе.
- `foldl` — последовательная обработка отсортированных интервалов.
- `merge` — объединение пересекающихся интервалов.
- `reverse` — восстановление правильного порядка результата.

Если начало следующего интервала не превышает конец предыдущего (`l2 <= r1`), интервалы объединяются. Новая правая граница определяется с помощью `max`.

**Временная сложность:** `O(n log n)`.  
**Дополнительная память:** `O(n)`.

## Тестирование

В программе предусмотрено 6 тестовых сценариев:

| Тест | Ожидаемый результат |
|---|---|
| Пересекающиеся интервалы | `[(1,6),(8,10),(15,18)]` |
| Вложенные интервалы | `[(1,10)]` |
| Соприкасающиеся интервалы | `[(1,7)]` |
| Непересекающиеся интервалы | Без изменений |
| Неотсортированные интервалы | `[(1,6),(8,12)]` |
| Пустой список | `[]` |
