# 3.1. Анализ результатов экзамена

**Язык:** Scheme  
**Тема:** Консольный и файловый ввод-вывод  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1eeYR_IyjBArwAQy-PMRLRSFg3bJ6GoIA/view?usp=sharing)

## Описание задачи

Программа анализирует результаты экзамена, считывая имена студентов и их баллы из текстового файла `students.txt`.

Вычисляются:
- Общее количество студентов.
- Средний, минимальный и максимальный баллы.
- Количество сдавших и не сдавших экзамен (проходной балл — 60).

Результаты выводятся в консоль и сохраняются в файл `report.txt`.

## Запуск

**Онлайн-среда:** [Try Scheme](https://try.scheme.org/)

1. Открыть Try Scheme.
2. Создать файл `main.scm` и вставить исходный код.
3. Нажать `Ctrl + Enter` для выполнения.
4. Открыть созданные файлы `students.txt` и `report.txt` через файловый редактор среды.

При первом запуске программа автоматически создаёт `students.txt` с тестовыми данными. При последующих запусках существующий файл сохраняется, а `report.txt` обновляется.

## Реализация

Основные функции:

- `create-file` — создание файла с исходными данными.
- `analyze-file` — чтение данных и рекурсивное вычисление статистики.
- `print-report` — формирование текстового отчёта.
- `save-report` — сохранение результатов в файл.
- `main` — последовательный запуск всех этапов.

Используются стандартные средства файлового ввода-вывода Scheme: `call-with-input-file`, `call-with-output-file`, `read` и `display`.

## Проверка работы

Для исходных данных из шести студентов ожидаются следующие результаты:

```text
=== Exam Results ===
Total students: 6
Average score: 68.
Minimum score: 41
Maximum score: 95
Passed students: 4
Failed students: 2
```

Также можно изменить оценки в `students.txt` и повторно запустить программу. Отчёт должен пересчитаться с учётом новых данных.
