# 3.3 Журнал
Разобрать строки timestamp level message, подсчитать уровни и сохранить ошибки за заданный период. Формат времени — YYYY-MM-DD HH:MM:SS; границы периода включены. Сообщить номера неверных строк.

# Perl. Сссылка на решение https://drive.google.com/file/d/1Zhk7lxP1A1dPgZWAmfNzyVnGHh1Qcgcj/view?usp=sharing
## Возможности

- Считывание журнала из UTF-8 файла формата `YYYY-MM-DDTHH:MM:SS LEVEL message`.
- Подсчёт количества сообщений уровней `DEBUG`, `INFO`, `WARN`, `ERROR` за весь журнал.
- Отбор строк `ERROR` за включительный период `[начало, конец]`.
- Сохранение статистики в `report.txt`, выбранных ошибок — в `errors_period.txt`.
- Проверка дат и учёт некорректных строк журнала.
- 11 автоматических тестов, включая чтение и запись реальных файлов.


## Установка (Windows)

1. Скачать [Strawberry Perl](https://strawberryperl.com/) для 64-битной Windows, установщик **MSI**, и установить.
2. Открыть новое окно PowerShell и проверить:

   ```powershell
   perl -v
   ```

## Запуск

Поместить `main.pl` и `log.txt` в одну папку, открыть PowerShell в этой папке.

```powershell
perl .\main.pl --test
perl .\main.pl
```

Первый запуск выполняет 11 автоматических тестов, второй обрабатывает `log.txt` с периодом по умолчанию от `2026-10-01T00:00:00` до `2026-10-03T23:59:59` (обе границы включительно).

Для своего временного диапазона:

```powershell
perl .\main.pl .\log.txt "2026-10-02T00:00:00" "2026-10-03T23:59:59"
```

Если нужно выбрать другой журнал, укажи его путь вместо `log.txt`. При некорректных датах или границах программа выдаёт сообщение об ошибке.

## Входной файл

`log.txt` — текстовый журнал, по одному сообщению на строку:

```text
2026-10-01T09:15:00 INFO Service started
2026-10-01T09:16:00 WARN Slow response
2026-10-01T09:17:12 ERROR Database unavailable
```

Допустимые уровни: `DEBUG`, `INFO`, `WARN`, `ERROR`. Даты и время задаются в формате `YYYY-MM-DDTHH:MM:SS` без часового пояса; все строки должны использовать одну временную шкалу. Пустые строки игнорируются, некорректные непустые строки учитываются в `Invalid lines`.

## Выходные файлы

- `report.txt` — общее количество корректных сообщений, число некорректных строк, частоты по уровням и количество ошибок за период.
- `errors_period.txt` — исходные строки ошибок `ERROR` за выбранный период.

Их можно открыть Блокнотом, чтобы продемонстрировать преподавателю результат файлового ввода-вывода.

## Ожидаемый результат для примера

```text
=== Log Analysis ===
Input file: log.txt
Period: 2026-10-01T00:00:00 to 2026-10-03T23:59:59
Total valid messages: 8
Invalid lines: 0

Messages by level:
DEBUG: 1
INFO: 2
WARN: 1
ERROR: 4

Errors in selected period: 3
```

`errors_period.txt` будет содержать три сообщения: `Database unavailable`, `Request failed`, `Timeout`. Ошибка из 4 октября будет исключена.
