# 3.4. Учёт личных расходов — Ruby

## Описание задачи

Разработать консольную программу для учёта личных расходов с использованием файлового ввода-вывода.

Программа должна обеспечивать добавление, просмотр, редактирование и удаление расходов, поиск по категориям и расчёт статистики. Данные должны сохраняться в текстовом файле и восстанавливаться при повторном запуске.

## Функциональность

- Добавление расхода с указанием даты, категории, суммы и описания.
- Просмотр всех сохранённых расходов.
- Редактирование существующей записи по идентификатору.
- Удаление расхода.
- Поиск расходов по категории.
- Расчёт общей суммы расходов и сумм по категориям.
- Проверка корректности введённых данных.
- Чтение и запись данных в текстовый файл.
- Автоматическое тестирование основных функций.

## Используемые технологии

- **Язык:** Ruby 3.4
- **Библиотеки:** стандартная библиотека `date`
- **Платформа:** Windows
- **Интерфейс:** консольный

Сторонние библиотеки не используются.

2. Проверить установку в PowerShell:

```powershell

```

3. Перейти в директорию проекта:

```powershell
cd путь\к\папке\проекта
```

4. Запустить программу:

```powershell

```

После запуска появится консольное меню:


Для выбора операции необходимо ввести соответствующий номер.

## Формат хранения данных

Каждая запись в `expenses.txt` имеет следующий формат:

```text
ID|Date|Category|Amount|Description
```

Пример содержимого файла:

```text
1|2026-10-31|Food|25050|Lunch
2|2026-10-31|Transport|8000|Metro
```

Суммы сохраняются в виде целых чисел в сотых долях денежной единицы. Например, значение `25050` соответствует сумме `250.50`.

Такой способ хранения позволяет избежать ошибок округления при арифметических операциях.

При запуске программа загружает данные из файла. После добавления, изменения или удаления записи файл автоматически обновляется.

Если `expenses.txt` отсутствует, программа создаёт его.

## Основные функции

- `load_expenses` — загрузка расходов из файла.
- `save_expenses` — сохранение расходов в файл.
- `add_expense` — добавление новой записи.
- `edit_expense` — редактирование расхода.
- `delete_expense` — удаление расхода.
- `show_expenses` — вывод списка расходов.
- `show_summary` — расчёт общей суммы и статистики по категориям.
- `valid_date?` — проверка даты.
- `parse_amount` — проверка и преобразование денежной суммы.
- `run_tests` — запуск автоматических тестов.

## Тестирование

Для выполнения тестов необходимо запустить программу и выбрать пункт `7 - Run tests`.

Реализовано семь автоматических проверок:

1. Сохранение и загрузка записей из файла.
2. Обработка дробных сумм с точкой.
3. Обработка дробных сумм с запятой.
4. Отклонение некорректных денежных сумм.
5. Проверка некорректных дат.
6. Вычисление общей суммы расходов.
7. Расчёт суммы расходов по категории.

Ожидаемый результат:

```text
Save and load: PASS
Decimal amount: PASS
Comma amount: PASS
Invalid amount: PASS
Invalid date: PASS
Total: PASS
Category sum: PASS
```

Тестирование выполняется на отдельных тестовых данных и не изменяет основной файл `expenses.txt`.
