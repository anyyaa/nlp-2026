# 3.4 Формирование отчёта о личных расходах

Считать из UTF-8 файла записи дата;категория;сумма. Через консоль задать период отчёта, вывести общую сумму и расходы по категориям, сохранить подробный отчёт в отдельный файл. Суммы хранить в целых копейках, даты — YYYY-MM-DD; границы периода включены. Сообщать номера неверных строк. Проверить пустой период, несколько категорий и неверные даты или суммы.
