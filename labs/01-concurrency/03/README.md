# 1.3 Параллельное вычисление гистограммы чисел

Считать из файла целые числа и границы диапазона. Разделить последовательность между потоками; каждый поток строит локальную гистограмму распределения по K равным интервалам. Объединить частоты и отдельно вывести количество значений вне диапазона. Последний интервал включает правую границу. Проверить совпадение с последовательным подсчётом, пустой вход и числа на границах интервалов.
