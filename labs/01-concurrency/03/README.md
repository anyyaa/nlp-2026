# 1.3. Многопоточная гистограмма чисел

**Язык:** Ada (Ada 2012)  
**Тема:** Многопоточность  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1Z8du1Zz9ZXf2alu7dFH2dbTy6XUqGcfz/view?usp=sharing)

## Описание задачи

Программа вычисляет гистограмму частот целых чисел от 0 до 9 с использованием нескольких параллельных задач Ada.

Реализованы:
- Проверка допустимых значений входного массива.
- Разделение массива на диапазоны между рабочими задачами.
- Независимый подсчёт частот для каждого диапазона.
- Безопасное объединение частичных гистограмм через `protected`.
- Вывод диапазонов, обработанных каждой задачей, и итоговой гистограммы.
- Автоматическое тестирование.

Используются стандартные возможности языка Ada: `task`, `entry` и `protected`.

## Запуск

**Среда:** [OneCompiler Ada](https://onecompiler.com/ada).

1. Открыть онлайн-компилятор.
2. Вставить содержимое `main.adb` вместо примера.
3. Нажать **Run**.

Ввод данных не требуется. Массив и количество задач заданы в программе:

```ada
Input : constant Numbers :=
  (3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5, 8, 9, 7, 9, 3, 0, 2, 4, 6);
Counts := Count_Parallel (Input, 4, True);
```

Для изменения числа задач достаточно заменить второй аргумент `Count_Parallel` (например, `4` на `2`). При изменении длины входного массива также нужно исправить информационную строку `Input length: 20`.

## Реализация

Основные компоненты:

- `Bin`, `Histogram`, `Numbers` — типы значений, гистограммы и входного массива.
- `Count_Sequential` — последовательный подсчёт для проверки.
- `Count_Parallel` — распределение вычислений между задачами и получение результата.
- `Collector_Type` — защищённый объект, который объединяет частичные гистограммы.
- `Submit` — передача результатов рабочей задачи в защищённый объект.
- `Wait_All` — ожидание завершения всех рабочих задач.
- `Worker`, `Configure` — рабочая задача и передача ей границ диапазона.
- `Check`, `Run_Tests` — выполнение автоматических проверок.
- `Main` — демонстрация работы программы.

Рабочие задачи обрабатывают независимые части массива. Каждая задача создаёт свою локальную гистограмму, а `Collector_Type` безопасно суммирует результаты. Основная программа ожидает их получения через `Wait_All`.

## Тестирование

Предусмотрено 15 автоматических тестов, проверяющих:

- Отдельные числа и повторяющиеся значения.
- Заполнение всех десяти категорий гистограммы.
- Пустой входной массив.
- Работу одного, двух, трёх и четырёх исполнителей.
- Ситуацию, когда задач больше, чем чисел.
- Неравномерное разделение диапазонов.
- Совпадение параллельного результата с последовательным.
- Обработку большого массива.
- Отклонение значений вне диапазона 0–9.

Ожидаемый результат при успешном выполнении:

```text
Passed: 15/15
```

При обработке демонстрационного массива из 20 элементов программа выводит частоты значений от 0 до 9 и сумму `Total counted: 20`.
