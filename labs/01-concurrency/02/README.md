# 1.2. Многопоточный поиск простых чисел

**Язык:** Kotlin (JVM)  
**Тема:** Многопоточность  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1VKs8XApHw_T5NjAKRLaA5O-p4TEPOy-K/view?usp=sharing)
## Описание задачи

Программа находит все простые числа в диапазоне от 2 до заданной верхней границы с использованием нескольких потоков.

Реализованы:
- Проверка чисел на простоту.
- Разделение диапазона на части между потоками.
- Параллельный поиск простых чисел.
- Объединение результатов в отсортированный список.
- Вывод информации о работе каждого потока.
- Автоматическое тестирование.

Используются стандартные средства JVM: `Thread`, `start()` и `join()`.

## Запуск

**Среда:** [Kotlin Playground](https://play.kotlinlang.org/).

1. Открыть Kotlin Playground и выбрать платформу **JVM**.
2. Вставить содержимое `main.kt` в редактор.
3. Нажать **Run**.

Ввод данных не требуется. Параметры задаются в функции `main`:

```kotlin
val limit = 100
val workerCount = 4
```

`limit` — верхняя граница диапазона, `workerCount` — количество рабочих потоков.

Для демонстрации можно изменять оба значения.

## Реализация

Основные компоненты:

- `WorkerResult` — хранит диапазон, найденные простые числа и имя потока.
- `isPrime` — проверяет число на простоту.
- `findPrimesParallel` — распределяет вычисления между потоками и объединяет результаты.
- `check` — выводит результат отдельной проверки.
- `runTests` — запускает автоматические тесты.
- `main` — демонстрирует работу программы.

Каждый поток обрабатывает собственный диапазон и записывает результат в отдельную ячейку массива.

После запуска потоков через `start()` основной поток ожидает их завершения с помощью `join()`.

Затем результаты объединяются в порядке диапазонов, поэтому итоговый список простых чисел отсортирован.

## Тестирование

Реализовано 15 автоматических тестов, проверяющих:

- Простые и составные числа.
- Корректность поиска в небольшом диапазоне.
- Пустые диапазоны.
- Работу одного и нескольких потоков.
- Ситуацию, когда потоков больше, чем чисел.
- Полноту покрытия диапазона.
- Совпадение параллельного результата с последовательным.
- Использование четырёх отдельных рабочих потоков.

Результат тестирования:

```text
Passed: 15/15
```

При `limit = 100` и `workerCount = 4` программа находит 25 простых чисел.
