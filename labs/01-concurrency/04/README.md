# 1.4. Параллельный поиск ближайшей пары точек

**Язык:** Julia 1.6+  
**Тема:** Многопоточность  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/13fxoFYjKhnaiTqKM1HAbhARaJvu6L0oD/view?usp=sharing)

## Описание задачи

Программа находит пару двумерных точек с минимальным евклидовым расстоянием полным перебором всех пар индексов `i < j`.

Реализованы:
- Разделение пар между рабочими задачами через `Threads.@spawn`.
- Вычисление локального минимума каждой задачи и объединение результатов.
- Выбор лексикографически меньшей пары индексов при равных расстояниях.
- Обработка пустого массива, одной точки и совпадающих точек.
- Сравнение результатов последовательного и параллельного алгоритмов.
- Сравнение времени выполнения с одним и четырьмя рабочими задачами.

Алгоритм использует стандартные возможности Julia без сторонних библиотек. Сложность по времени — `O(n²)`, дополнительная память — `O(k)`, где `k` — количество рабочих задач.

## Запуск

**Среда:** [CoCalc](https://cocalc.com/features/julia) — облачный терминал с Julia.

1. Создать проект CoCalc и загрузить в него `main.jl`.
2. Открыть терминал проекта.
3. Выполнить:

```bash
julia --threads=4 main.jl
```

## Реализация

Основные компоненты:

- `Point` — двумерная точка из двух координат `Float64`.
- `PairResult` — индексы ближайшей пары и квадрат расстояния.
- `WorkerInfo`, `SearchResult` — сведения о задачах и общий результат.
- `squared_distance` — вычисление квадрата евклидова расстояния без `sqrt` внутри циклов.
- `is_better` — сравнение пар по расстоянию, затем по индексам.
- `scan_worker` — перебор пар `i < j`, закреплённых за одной задачей.
- `closest_sequential` — последовательное эталонное решение.
- `closest_parallel` — запуск задач через `Threads.@spawn`, ожидание через `fetch` и объединение минимумов.
- `run_tests` — 22 автоматические проверки.
- `measure` — замер времени, лучший результат из трёх запусков после прогрева.
- `main` — демонстрация, тесты и сравнение времени.

В `scan_worker` рабочая задача с номером `id` получает строки `i = id, id + worker_count, ...`, для каждой из которых проверяет все `j > i`. Таким образом, любая пара рассматривается ровно один раз. Рабочие задачи изменяют только свои локальные переменные, поэтому блокировки не нужны.

## Тестирование

Предусмотрено 22 теста: пустой массив, одна точка, две точки, точность расстояния, горизонтальные и вертикальные точки, отрицательные координаты, совпадающие точки, равные расстояния, один/несколько исполнителей, число исполнителей больше доступных строк, полнота перебора пар, воспроизводимость, неверное число исполнителей и сравнение на большом автоматически сгенерированном наборе.

Ожидаемый итог успешного запуска:

```text
Passed: 22/22
```

Для демонстрационного массива из 8 точек ближайшая пара — `(1, 6)`, расстояние — `1.0`. При равенстве расстояний программа выбирает меньшую по индексам пару.

В разделе `Benchmark` выводятся время для одного и четырёх исполнителей, отношение времён и проверка `Results equal: true`. Время и ускорение зависят от компьютера и числа потоков Julia.
