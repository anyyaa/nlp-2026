# 1.4 Параллельный поиск ближайшей пары точек

Для набора двумерных точек найти пару с минимальным евклидовым расстоянием. Распределить пары индексов i < j между потоками; каждый сохраняет локальный минимум, затем результаты объединяются. При равных расстояниях выбирать лексикографически меньшую пару индексов. Использовать перебор без специализированных библиотек. Сравнить результаты и время при одном и нескольких потоках; проверить совпадающие точки и вход менее чем из двух точек.
