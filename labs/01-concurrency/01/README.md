# 1.1. Многопоточный подсчёт частоты слов

**Язык:** D  
**Тема:** Многопоточность  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1OBt1RVVMx-RfgA2o9eevHfvNH5szI7vh/view?usp=sharing)

## Описание задачи

Программа подсчитывает частоту появления слов в тексте с использованием нескольких потоков.

Реализованы:
- Разбиение текста на слова с поддержкой латиницы, кириллицы и цифр.
- Приведение слов к нижнему регистру.
- Распределение массива слов между несколькими потоками.
- Независимый подсчёт частот в каждом потоке.
- Объединение результатов после завершения потоков.
- Вывод статистики работы каждого потока.

Используются стандартные потоки D (`core.thread.Thread`).

## Запуск

**Среда:** [D Online Editor](https://run.dlang.io/).

1. Открыть онлайн-компилятор.
2. Вставить содержимое `main.d` в редактор.
3. Нажать **Run**.

Ввод данных не требуется. Исходный текст и количество потоков задаются в функции `main`:

```d
string text = "Data data DATA! Parallel threads count words. " ~
              "Threads work in parallel. Кот кот КОТ.";
size_t workers = 4;
```

Для проверки работы с другим количеством потоков можно изменить `workers`.

## Реализация

Основные компоненты:

- `WorkerInfo` — информация об отдельном рабочем потоке.
- `Analysis` — общий результат обработки.
- `splitWords` — разбиение текста на слова.
- `countRange` — подсчёт частот в заданном диапазоне.
- `WordWorker` — рабочий поток с собственным словарём частот.
- `countParallel` — создание потоков, распределение работы и объединение результатов.
- `sameCounts` — сравнение словарей.
- `runTests` — автоматические проверки.
- `main` — запуск программы и вывод результатов.

Потоки запускаются через `start()`, а основной поток ожидает их завершения с помощью `join()`.

Каждый поток изменяет только собственный словарь, поэтому дополнительная блокировка при подсчёте не требуется.

## Тестирование

Предусмотрено 15 автоматических тестов, проверяющих:

- Игнорирование регистра.
- Обработку знаков препинания, цифр и кириллицы.
- Пустой текст и отдельные слова.
- Работу с разным количеством потоков.
- Корректность распределения диапазонов.
- Отсутствие потерянных слов.
- Совпадение параллельного результата с последовательным.

Результат успешного тестирования:

```text
Passed: 15/15
```

Для тестового текста программа обрабатывает 14 слов, из которых 8 уникальных.
