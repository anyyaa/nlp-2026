# 5.2. Конвертация текста в азбуку Морзе и обратно

**Язык:** Lua  
**Тема:** Конвертация данных из одного формата в другой  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/13BMB4L3V5GWcihXpJyv7jQNtzClHoGWG/view?usp=sharing)

## Описание задачи

Реализовать консольную программу для преобразования обычного текста в азбуку Морзе и обратно.

Программа поддерживает латинские буквы, цифры, пробелы и основные знаки препинания.

Предусмотрены обработка некорректных символов, обратное преобразование и автоматическое тестирование.

## Запуск

**Среда выполнения:** Lua 5.5, Windows  
**Скачать Lua:** https://luabinaries.sourceforge.net/

1. Скачать и распаковать Lua для Windows.
2. Поместить `main.lua` в папку с `lua55.exe`.
3. Открыть PowerShell в этой папке.
4. Выполнить команду:

```powershell
.\lua55.exe .\main.lua
```

После запуска появится консольное меню:

```text
1 - Text to Morse
2 - Morse to text
3 - Run tests
0 - Exit
Choose:
```

## Реализация

Основные компоненты программы:

- `morse` — таблица соответствия символов кодам Морзе.
- `letters` — обратная таблица для декодирования.
- `encode` — преобразование текста в азбуку Морзе.
- `decode` — восстановление текста из кода Морзе.
- `run_tests` — автоматическое тестирование.

Символы Морзе разделяются пробелами, а слова — символом `/`.

## Тестирование

В программе предусмотрено 6 автоматических проверок:

| Тест | Ожидаемый результат |
|---|---|
| `SOS` | `... --- ...` |
| `HELLO WORLD` | Корректное кодирование и декодирование |
| `2026` | Преобразование цифр |
| `A, B` | Обработка знаков препинания |
| `HELLO#` | Ошибка неподдерживаемого символа |
| Некорректный код Морзе | Сообщение об ошибке |

Для запуска тестов необходимо выбрать пункт `3` в меню.
