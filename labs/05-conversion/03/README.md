# 5.3. Конвертация CSV в XML

**Язык:** Clojure  
**Тема:** Конвертация данных  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1SA7iip7dDvhxp4tdrOm7NlyyuaYedeIG/view?usp=sharing)

## Описание задачи

Программа преобразует данные из текстового файла CSV в XML-документ без использования специализированных библиотек.

Реализованы:
- Самостоятельный разбор CSV с поддержкой кавычек, запятых внутри полей и многострочных значений.
- Преобразование заголовков CSV в названия XML-элементов.
- Экранирование специальных символов XML.
- Проверка корректности входных данных.
- Сохранение результата в отдельный XML-файл.

## Запуск

**Среда:** Clojure 1.12.6, Java, Windows PowerShell.

Открыть PowerShell в папке проекта.

**Запуск автоматических тестов:**

```powershell
clojure -M .\main.clj --test
```

**Запуск конвертера:**

```powershell
clojure -M .\main.clj
```

Программа считывает `input.csv` и создаёт `output.xml`.

**Просмотр результата:**

```powershell
Get-Content .\output.xml
```

**Сравнение с эталоном:**

```powershell
(Get-Content .\output.xml -Raw -Encoding UTF8) -eq (Get-Content .\expected.xml -Raw -Encoding UTF8)
```

Результат `True` означает, что полученный XML совпадает с эталоном.

Также поддерживается указание собственных файлов:

```powershell
clojure -M .\main.clj .\data.csv .\result.xml
```

## Реализация

Основные функции:

- `parse-csv` — посимвольный разбор CSV с использованием рекурсивного `loop` и состояний парсера.
- `xml-tag` — формирование корректных названий XML-тегов.
- `xml-escape` — экранирование символов `&`, `<`, `>`, кавычек и апострофов.
- `csv-to-xml` — проверка данных и формирование XML-документа.
- `convert-file` — чтение CSV и сохранение XML в кодировке UTF-8.
- `run-tests` — запуск автоматических проверок.
- `-main` — обработка аргументов и запуск программы.

## Тестирование

Предусмотрено 15 автоматических тестов, проверяющих:

- Обычное преобразование CSV в XML.
- Запятые и двойные кавычки внутри полей.
- Экранирование специальных символов XML.
- Многострочные значения.
- Windows-переносы строк и BOM.
- Преобразование некорректных названий тегов.
- Пустые поля, недостающие и лишние столбцы.
- Ошибки кавычек и дублирующиеся заголовки.
- Реальное чтение и запись файлов.

Ожидаемый итог успешного тестирования:

```text
Passed: 15/15
```

Пример преобразования:

**CSV:**

```csv
name,category,description,amount
Anna,Food,"Bread, milk & tea",250.50
```

**XML:**

```xml
<records>
  <record>
    <name>Anna</name>
    <category>Food</category>
    <description>Bread, milk &amp; tea</description>
    <amount>250.50</amount>
  </record>
</records>
```
