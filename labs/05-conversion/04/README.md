# 5.4. Конвертация BMP в PGM

**Язык:** Nim  
**Тема:** Конвертация данных  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1yj4AmXFyhL2w3NebS7C60IXbNUg3PXgU/view?usp=sharing)

## Описание задачи

Программа преобразует цветное изображение формата BMP в чёрно-белое изображение в оттенках серого формата PGM без использования специализированных библиотек.

Реализованы:
- Чтение бинарной структуры 24-битного BMP без сжатия.
- Проверка заголовка и параметров изображения.
- Извлечение RGB-компонентов каждого пикселя.
- Преобразование RGB в оттенки серого по взвешенной формуле.
- Учёт выравнивания строк и порядка хранения пикселей BMP.
- Сохранение результата в текстовом формате PGM P2.

## Запуск

**Среда:** Nim 2.4.0, Windows PowerShell.

Открыть PowerShell в папке проекта.

**Компиляция программы:**

```powershell
nim c -d:release .\main.nim
```

**Запуск автоматических тестов:**

```powershell
.\main.exe --test
```

**Запуск конвертера:**

```powershell
.\main.exe
```

Программа считывает `input.bmp` и создаёт `output.pgm`.

**Просмотр результата:**

```powershell
Get-Content .\output.pgm
```

**Сравнение с эталоном:**

```powershell
Compare-Object (Get-Content .\output.pgm) (Get-Content .\expected.pgm)
```

Если команда ничего не выводит, файлы совпадают.

Если Nim не добавлен в `PATH`, необходимо использовать полный путь к `nim.exe` при компиляции.

## Реализация

Основные функции:

- `getU16`, `getU32` — чтение 16-битных и 32-битных чисел из бинарных данных BMP.
- `convertBmp` — проверка заголовка, чтение пикселей, преобразование RGB в оттенки серого и формирование PGM.
- `fails` — проверка возникновения ошибок при некорректных входных данных.
- `check` — проверка результата отдельного теста.
- `runTests` — запуск автоматических тестов.
- `when isMainModule` — обработка аргументов командной строки и запуск программы.

Для вычисления яркости пикселя используется формула:

\[
Y = \frac{299R + 587G + 114B}{1000}
\]

Результат округляется до целого значения от 0 до 255.

## Тестирование

В программе предусмотрено 14 автоматических тестов, проверяющих:

- Корректное преобразование BMP в PGM.
- Правильность вычисления оттенков серого.
- Обработку изображений с разным порядком строк.
- Учёт дополнительных байтов выравнивания.
- Некорректную сигнатуру и повреждённый заголовок BMP.
- Неподдерживаемую глубину цвета и сжатие.
- Отсутствующие пиксельные данные.
- Запись результата в файл.

Ожидаемый итог успешного тестирования:

```text
Passed: 14/14
```

Для тестового изображения размером 3×3 пикселя ожидается следующий результат:

```text
P2
3 3
255
76 150 29
255 0 226
179 105 128
```

`P2` обозначает текстовый формат PGM, `3 3` — размеры изображения, `255` — максимальную яркость. Последующие значения соответствуют яркости отдельных пикселей.
