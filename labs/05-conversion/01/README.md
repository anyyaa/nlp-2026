# 5.1 Конвертация Intel HEX в бинарный файл

Самостоятельно разобрать текстовые записи Intel HEX и сохранить байты в бинарный файл. Учебный объём: записи данных типа 00 и конца файла типа 01, 16-битные адреса; остальные типы явно отклонять. Проверять длину записи и контрольную сумму, пересекающиеся адреса считать ошибкой. Выход начинается с адреса 0, пропуски до максимального записанного адреса заполнить нулями. Проверить запись :03000000010203F7 → байты 01 02 03 и завершение :00000001FF.
