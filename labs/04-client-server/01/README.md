# 4.1. Сервер обработки строк

**Язык:** Groovy  
**Тема:** Клиент-серверное взаимодействие  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1dvAd0DUrSN_WL_TZ46GD9JEWPKigWKqD/view?usp=sharing)

## Описание задачи

Реализовать клиент-серверное приложение для обработки строк с использованием TCP-соединения.

Клиент отправляет серверу строку и команду. Сервер выполняет одну из четырёх операций:

- `UPPER` — перевод в верхний регистр.
- `LOWER` — перевод в нижний регистр.
- `REVERSE` — разворот строки.
- `LENGTH` — определение длины строки.

Предусмотрены обработка ошибок и одновременное подключение нескольких клиентов.

## Запуск

**Среда выполнения:** Apache Groovy 5.1.3, Java JDK, Windows  
**Скачать Groovy:** https://groovy.apache.org/download.html

1. Установить Java JDK и скачать Binary ZIP Apache Groovy.
2. Распаковать Groovy и добавить папку `bin` в `PATH`.
3. Открыть PowerShell в корневой папке проекта.
4. Перейти в папку с исходным кодом:

```powershell
cd src
```

**Запуск тестов:**

```powershell
groovy .\tests.groovy
```

**Запуск сервера (первое окно PowerShell):**

```powershell
groovy .\server.groovy
```

**Запуск клиента (второе окно PowerShell, также из папки `src`):**

```powershell
groovy .\client.groovy
```

Если Groovy не добавлен в `PATH`, необходимо использовать полный путь к `groovy.bat`.

Сервер работает по адресу `127.0.0.1:5050`.

После запуска клиента появляется меню:

```text
1 - Uppercase
2 - Lowercase
3 - Reverse
4 - Length
0 - Exit
Choose:
```

Для остановки сервера используется `Ctrl+C`.

## Реализация

Основные компоненты программы:

- `StringServer` — класс TCP-сервера.
- `process` — обработка команд и строк.
- `handleClient` — получение запросов и отправка ответов.
- `serve` — ожидание подключений и создание потоков.
- `client.groovy` — отправка запросов и отображение результатов.

Для каждого клиента создаётся отдельный поток `Thread`, позволяющий обрабатывать несколько подключений одновременно.

Обмен сообщениями осуществляется по TCP в кодировке UTF-8. Используются стандартные сетевые средства Java.

## Тестирование

В программе предусмотрено 16 автоматических проверок:

| Тест | Ожидаемый результат |
|---|---|
| `UPPER hello` | `HELLO` |
| `LOWER HeLLo` | `hello` |
| `REVERSE Groovy` | `yvoorG` |
| `LENGTH Hello` | `5` |
| Пустая строка | Корректная обработка |
| Неизвестная команда | Сообщение об ошибке |
| Unicode-символы | Корректная обработка |
| Четыре одновременных клиента | Успешная обработка запросов |

Также проверяются реальные TCP-соединения и сохранение пробелов.

Ожидаемый итог тестирования:

```text
Passed: 16/16
```
