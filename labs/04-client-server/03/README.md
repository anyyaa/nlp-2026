# 4.3 Ручной HTTP-клиент
Отправить GET по TCP и самостоятельно разобрать статус, заголовки и тело. Учебный объём: HTTP/1.1 без TLS, с Connection: close; поддержать Content-Length и тело до закрытия. Неподдерживаемую Transfer-Encoding явно отклонить. Проверять на локальном сервере с фиксированными ответами.
