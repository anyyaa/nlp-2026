# 4.4. Многопользовательский TCP-чат

**Язык:** Erlang  
**Тема:** Клиент-серверное взаимодействие  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1iwWAAjMjYeyT2ZwsrGEbBLAn5mF7FKMN/view?usp=sharing)

## Описание задачи

Программа реализует многопользовательский TCP-чат на Erlang с использованием стандартного модуля `gen_tcp`.

Реализованы:
- Одновременное подключение нескольких клиентов.
- Регистрация пользователей с уникальными именами.
- Обмен сообщениями между участниками.
- Рассылка уведомлений о подключении и отключении.
- Просмотр списка активных пользователей.
- Обработка некорректных команд и сетевых ошибок.

Для каждого подключения создаётся отдельный процесс Erlang.

## Запуск

**Среда:** Erlang/OTP 29.1, Windows PowerShell.

Открыть PowerShell в папке проекта и перейти в `src`:

```powershell
cd src
```

Если Erlang не добавлен в `PATH`, подключить установленную версию:

```powershell
$env:Path = "$env:USERPROFILE\.elixir-install\installs\otp\29.1\bin;$env:Path"
```

**Компиляция:**

```powershell
erlc .\chat_protocol.erl .\chat_server.erl .\chat_client.erl .\chat_tests.erl
```

**Запуск автоматических тестов:**

```powershell
erl -noshell -pa . -s chat_tests main
```

**Запуск сервера (первое окно PowerShell):**

```powershell
erl -noshell -pa . -s chat_server main
```

Сервер работает по адресу `127.0.0.1:5052`.

**Первый клиент (второе окно PowerShell):**

```powershell
erl -noshell -pa . -s chat_client main -extra Anna
```

**Второй клиент (третье окно PowerShell):**

```powershell
erl -noshell -pa . -s chat_client main -extra Boris
```

Для каждого нового окна PowerShell необходимо повторить настройку `PATH`, если Erlang не добавлен в него постоянно.

В клиенте доступны команды:

- Обычный текст — отправка сообщения всем участникам.
- `/users` — просмотр подключённых пользователей.
- `/quit` — выход из чата.

Для остановки сервера используется `Ctrl+C`.

## Реализация

Основные компоненты:

- `chat_protocol.erl` — проверка имён пользователей и разбор команд `NICK`, `MSG`, `USERS`, `QUIT`.
- `chat_server.erl` — TCP-сервер, управление подключениями и рассылка сообщений.
- `chat_client.erl` — консольный клиент для отправки и получения сообщений.
- `chat_tests.erl` — автоматическое тестирование протокола и сетевого взаимодействия.

Основные функции:

- `start`, `accept_loop` — запуск сервера и приём подключений.
- `socket_loop`, `handle_line` — обработка сообщений отдельного клиента.
- `hub_loop` — регистрация пользователей и управление состоянием чата.
- `broadcast` — рассылка сообщений всем участникам.
- `receive_loop`, `input_loop` — получение сообщений и обработка пользовательского ввода.
- `run_protocol_checks`, `run_network_checks` — автоматические проверки.

Для параллельной работы используются процессы Erlang, создаваемые с помощью `spawn`.

## Тестирование

В программе предусмотрено 25 автоматических тестов, проверяющих:

- Корректность имён пользователей.
- Разбор команд протокола.
- Обработку пустых и слишком длинных сообщений.
- Поддержку UTF-8.
- Запрет отправки сообщений до регистрации.
- Уникальность имён участников.
- Одновременное подключение нескольких клиентов.
- Рассылку сообщений всем пользователям.
- Получение актуального списка участников.
- Уведомления о входе и выходе из чата.

Ожидаемый итог успешного тестирования:

```text
Passed: 25/25
```
