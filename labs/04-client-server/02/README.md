# 4.2. Клиент-серверная игра «Быки и коровы»

**Язык:** Elixir  
**Тема:** Клиент-серверное взаимодействие  
**Видео с демонстрацией:** [Ссылка на видео](https://drive.google.com/file/d/1GL97Il477kGqEs9BYblNAwVm2p9XY0SA/view?usp=sharing)

## Описание задачи

Реализовать клиент-серверную игру «Быки и коровы» с использованием TCP-соединений.

Сервер загадывает четырёхзначное число без повторяющихся цифр. Клиент отправляет варианты ответа, а сервер сообщает:

- **Быки** — цифры на правильных позициях.
- **Коровы** — правильные цифры на других позициях.

Программа поддерживает одновременное подключение нескольких клиентов с независимыми игровыми сессиями, обработку некорректного ввода и подсчёт попыток.

## Запуск

**Среда выполнения:** Elixir 1.20.5, Erlang/OTP 29.1, Windows  
**Установка:** https://elixir-lang.org/install.html

1. Установить Erlang/OTP и Elixir.
2. Открыть PowerShell в корневой папке проекта.
3. Перейти в папку с исходным кодом:

```powershell
cd src
```

**Запуск тестов:**

```powershell
elixir.bat .\tests.exs
```

**Запуск сервера (первое окно PowerShell):**

```powershell
elixir.bat .\server.exs
```

**Запуск клиента (второе окно PowerShell):**

```powershell
elixir.bat .\client.exs
```

Для подключения второго игрока необходимо открыть третье окно PowerShell и запустить `client.exs` ещё раз.

Сервер работает по адресу `127.0.0.1:5051`.

Для демонстрации предусмотрен режим с заранее известными числами:

```powershell
elixir.bat .\server.exs --demo
```

В этом режиме первому клиенту назначается число `1234`, второму — `5678`.

Если Elixir не добавлен в `PATH`, необходимо использовать полный путь к `elixir.bat`.

Для остановки сервера используется `Ctrl+C`.

## Реализация

Основные компоненты программы:

- `game.exs` — генерация секретного числа, проверка ввода и подсчёт быков и коров.
- `server_core.exs` — TCP-сервер и управление клиентскими сессиями.
- `server.exs` — запуск сервера и демонстрационного режима.
- `client.exs` — отправка попыток и получение ответов.
- `tests.exs` — автоматическое тестирование.

Для каждого подключённого клиента создаётся отдельный процесс Elixir. Каждый процесс хранит собственное секретное число и счётчик попыток.

Для сетевого обмена используется стандартный модуль Erlang `gen_tcp`.

## Тестирование

В программе предусмотрено 16 автоматических тестов:

| Тест | Ожидаемый результат |
|---|---|
| Генерация секретного числа | 4 различные цифры |
| `1234` при загаданном `1234` | 4 быка, 0 коров |
| `4321` при загаданном `1234` | 0 быков, 4 коровы |
| `1243` при загаданном `1234` | 2 быка, 2 коровы |
| Некорректное число | Сообщение `ERROR` |
| Правильное число | Сообщение `WIN` |
| Команда `QUIT` | Завершение сессии |
| Два одновременных клиента | Независимая работа |

Также проверяются корректность генерации чисел, подсчёт попыток и выполнение команды `HELP`.
