# 4.2 Клиент-серверная игра «Быки и коровы»

Сервер создаёт для каждого клиента секрет из четырёх различных цифр, первая цифра ненулевая. Клиент отправляет догадки; сервер возвращает число быков (верная цифра на верной позиции) и коров (верная цифра на другой позиции), а также число попыток. Реализовать команды новой игры и выхода, независимые сеансы по TCP. Проверить повторы цифр, неверную длину, победу и одновременную игру двух клиентов. Для проверок разрешить серверу фиксированный секрет.
